DMd Windows desktop

Run the DMd setup executable to install for the current Windows user. The installer
contains the WebView2 installer for machines that need it, including offline setup.
After installation, open DMd from the Start menu.

The supplementary portable folder contains DMd.exe and its required content and
license resources. Keep that folder intact. It requires an installed WebView2 runtime.
The installer is the supported route for a machine without WebView2.

Open DMd, create a campaign and save its table agreement. In host setup, add players,
create characters using the supported source profile, and start a session with their
attendance and character bindings. The host can establish a situation and challenges;
select a player channel to speak, propose an action, correct it and enter physical dice.
Questions and table chat remain separate from accepted world outcomes. Closing and
reopening DMd preserves saved campaigns, pending decisions and unconfirmed requests.
No developer server or network connection is required for the local table loop.

This is a Gate 3 development package. The source profile and executed mechanics are
bounded; character sheets identify feature execution scope. It does not include the
later gates' complete tactical rules, progression or content catalog. Check the exact
build's gate evidence before treating it as an accepted release.

build-info.json identifies the exact source commit and target. SHA256SUMS.txt records
the packaged file hashes. portable/licenses/dependencies contains license declarations
and available upstream notice texts, including build tooling. SRD attribution and
license notices remain alongside the rules content.
