# Transcript Interaction Regression Corpus

This directory contains sanitized, campaign-agnostic interaction fixtures derived from real tabletop behavior patterns.

Fixtures test the conversation layer, not a specific campaign.

Required categories include:

- speech-recognition corruption of character/entity names;
- compound multi-character declarations;
- simultaneous action + dialogue + rules question;
- physical-dice result association;
- correction before commit;
- retcon request after commit;
- table chatter vs committed action;
- routine exploration compression;
- standing intentions and stop conditions;
- split-party scenes;
- PvP actions that require another human PC's response;
- genuine ambiguity that requires clarification;
- harmless ambiguity that should be inferred without interrupting play.

Raw private campaign transcripts do not belong in this public repository.
